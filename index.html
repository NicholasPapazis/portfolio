PortalPro - Student Registration Application

PortalPro simplifies the process of managing student records. Whether you're adding, updating, or viewing student data, this application provides a clean, intuitive interface and powerful features to keep everything organized.

Features

  • 1. CRUD Functionality - Create, Read, Update, and Delete student records with ease.
  • 2. Advanced Registration with Validation - Ensures valid @farmingdale.edu email and password validation using regex.
  • 3. User Session and Preferences - Implemented signup/login with the Java Preferences API and stores credentials upon sign-in.
  • 4. Azure SQL Database Integration - Secure and scalable data storage in Azure SQL Database.
  • 5. Profile Image Storage - Upload and store student profile images in Azure Blob Storage.
  • 6. User Feedback & Status Bar - Real-time feedback with status bar (e.g., successful registrations or import status).
  • 7. Edit Records Directly in the Table - Inline editing of student records, with immediate database updates.
  • 8. Import/Export CSV - Import/export student data in CSV format for backup or analysis.
  • 9. Generate PDF Reports - Generate student reports with visualized data such as bar charts.
  • 10. Thread-Safe User Sessions - Thread-safe management of user sessions for smooth concurrent usage.

Technologies Used

  • JavaFX: The user interface is built with JavaFX for a modern desktop experience.
  • Azure SQL Database: Secure and scalable cloud database for storing student data.
  • Azure Blob Storage: Used for securely storing student profile images in the cloud.
  • Regular Expressions (Regex): Used for validating email and password inputs during registration.
  • Java Preferences API: Manages user preferences and settings across sessions.
